-----
### 컨슈머 주요 옵션 (필수 옵션)
-----
1. bootstrap.servers : 프로듀서가 데이터를 전송할 대상 카프카 클러스터에 속한 브로커의 호스트 이름:포트를 1개 이상 작성
   - 2개 이상 브로커 정보를 입력하여 일부 브로커에 이슈가 발생하더라도 접속하는 데 이슈가 없도록 설정 가능
2. key.deserializer : 레코드의 메세지 키를 역직렬화하는 클래스를 지정
3. value.deserializer : 레코드의 메세지 값을 역직렬화하는 클래스를 지정

-----
### 컨슈머 주요 옵션 (선택 옵션)
-----
1. 💡 group.id : 컨슈머 그룹 아이디를 지정
   - subscribe() 메서드로 토픽을 구독하여 사용할 때는 이 옵션을 필수로 넣어야 함 (assign()과 같이 토픽을 할당해서 사용할 때는 필수는 아님)
   - 기본값은 null

2. auto.offset.reset : 컨슈머 그룹이 특정 파티션을 읽을 때 저장된 컨슈머 오프셋이 없을 경우 어느 오프셋부터 읽을지 선택하는 옵션
   - 이미 컨슈머 오프셋이 있다면 이 옵션값은 무시
   - 기본값은 latest

3. enable.auto.commit : 자동 커밋으로 할지, 수동 커밋으로 할지 선택 (기본값은 true)

4. auto.commit.interval.ms : 자동 커밋일 경우 오프셋 커밋 간격 지정 (기본값은 5000(5초))

5. max.poll.records : poll() 메서드를 통해 반환되는 레코드 개수 지정 (기본값 500)

6. session.timeout.ms : 컨슈머가 브로커와 연결이 끊기는 최대 시간 (기본값 10000(10초))

7. heartbeat.interval.ms : 하트비트를 전송하는 시간 간격 (기본값 3000(3초))

8. max.poll.interval.ms : poll() 메서드를 호출하는 간격의 최대 시간 (기본값은 300000(5분))

9. isolation.level : 트랜잭션 프로듀서가 레코드를 트랜잭션 단위로 보낼 경우 사용
