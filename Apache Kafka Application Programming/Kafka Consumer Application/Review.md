-----
### 정리
-----
1. 컨슈머는 토픽에 저장된 데이터를 가져가서 처리 하는 용도로 활용
2. 컨슈머 그룹은 1개 이상 컨슈머로 구성
3. 컨슈머 그룹의 컨슈머 갯수는 파티션 개수와 같거나 적어야 최대의 효율을 냄
4. 서로 다른 컨슈머 그룹은 데이터 처리에 영향을 미치지 않음
5. 컨슈머와 파티션의 재할당 과정을 리밸런싱이라 부름
6. 컨슈머가 어느 레코드까지 읽었는지 기록하기 위해 오프셋을 기록 (커밋)

-----
### 퀴즈
-----
1. 1개 컨슈머는 여러 개의 파티션에 할당될 수 있음 (O)
2. (동일한 컨슈머 그룹) 하나의 파티션은 여러 컨슈머에 할당될 수 있음 (X)
3. 파티션 개수보다 컨슈머 그룹의 컨슈머 개수가 많으면 오류가 발생 (X)
4. 안정적인 데이터 처리를 위해 session.timeout.ms는 heartbeat.interval.ms보다 작은 값이어야 함 (X)
5. 컨슈머를 안정적으로 종료하기 위해 session.timeout.ms를 사용 (X) : session.timeout.ms는 리밸런싱 목적
