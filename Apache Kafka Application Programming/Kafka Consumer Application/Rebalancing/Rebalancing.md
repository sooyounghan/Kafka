-----
### 리밸런싱
-----
<div align="center">
<img src="https://github.com/user-attachments/assets/85cca700-5e9a-42b6-a578-9273266a8f6a" />
</div>

1. 컨슈머 그룹으로 이루어진 컨슈머들 중 일부 컨슈머에 장애가 발생하면, 장애가 발생한 컨슈머에 할당된 파티션은 장애가 발생하지 않은 컨슈머에 소유권이 넘어가는데, 이러한 과정을 '리밸런싱(Rebalancing)'
2. 리밸런싱은 크게 두 가지 상황에서 일어남
   - 첫 번째 : 컨슈머가 추가되는 상황
   - 두 번째 : 컨슈머가 제외되는 상황

3. 이슈가 발생한 컨슈머를 컨슈머 그룹에서 제외하여 모든 파티션이 지속적으로 데이터를 처리할 수 있도록 가용성을 높여줌
4. 리밸런싱은 컨슈머가 데이터를 처리하는 도중에 언제든지 발생할 수 있으므로 데이터 처리 중 발생한 리밸런싱에 대응하는 코드를 작성해야 함
