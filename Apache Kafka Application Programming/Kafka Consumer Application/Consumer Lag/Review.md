-----
### 정리
-----
1. 컨슈머 랙은 파티션의 최신 오프셋과 컨슈머 오프셋 간의 차이
2. 컨슈머 랙은 컨슈머 애플리케이션을 운영할 때 반드시 모니터링 해야함
3. 컨슈머 랙은 파티션 별로, 컨슈머 그룹별로 생성됨
4. 컨슈머 처리량 보다 프로듀서의 처리량이 많을 경우 컨슈머 랙이 반드시 발생
5. 카프카 명령어 또는 metrics() 메서드를 사용하면 컨슈머 랙을 확인할 수 있음
6. 컨슈머 랙을 확인하는 방법 중 하나는 외부 모니터링 툴인 버로우(Burrow)를 확인하는 것
7. 카프카 버로우는 슬라이딩 윈도우를 통해 컨슈머 랙을 평가

-----
### 퀴즈
-----
1. 컨슈머 랙은 토픽별로 1개 측정할 수 있음 (X)
2. 파티션 개수가 50개인 토픽의 컨슈머 랙은 50개가 측정 (X) - 컨슈머 그룹이 1개라면 O, 컨슈머 그룹이 n개면 50 * n개
3. 컨슈머 랙을 모니터링하는 가장 좋은 방법은 외부 모니터링 툴을 사용하는 것 (O)
4. 프로듀서의 전송량이 초당 10개, 컨슈머의 처리량이 초당 1개, 파티션이 20개면 컨슈머 랙이 증가 (X)
   - 파티션 개수가 20개이므로, 컨슈머도 20개 : 초당 20개의 데이터 처리량
   - 프로듀서 전송량보다 컨슈머 처리량이 많으므로 컨슈머 랙이 증가하지 않음
