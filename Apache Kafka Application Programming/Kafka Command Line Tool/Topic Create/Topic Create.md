### 토픽을 생성하는 2가지 방법
-----
1. 토픽을 생성하는 2가지 상황
   - 첫 번째 상황 : 카프카 컨슈머 또는 프로듀서가 카프카 브로커에 생성되지 않은 토픽에 대해 데이터를 요청할 때
   - 두 번째 상황 : 커맨드 라인 툴로 명시적으로 토픽을 생성하는 것

2. 토픽을 효과적으로 유지보수하기 위해서는 토픽을 명시적으로 생성하는 것을 추천
   - 토픽마다 처리되어야 하는 데이터의 특성이 다르기 때문임

3. 토픽을 생성할 때는 데이터 특성에 따라 옵션을 다르게 생성할 수 있음
   - 예를 들어, 동시 데이터 처리량이 많아야 하는 토픽의 경우 파티션의 개수를 100으로 설정할 수 있음
   - 단기간 데이터 처리만 필요한 경우에는 토픽에 들어온 데이터의 보관기간 옵션을 짧게 설정할 수 있음
   - 그러므로 토픽에 들어오는 데이터 양과 병렬로 처리되어야 하는 용량을 잘 파악하여 생성하는 것이 중요
