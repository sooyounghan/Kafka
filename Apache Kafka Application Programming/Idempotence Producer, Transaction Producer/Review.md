-----
### 정리
-----
1. 전달 신뢰성은 적어도 한 번, 최대 한 번, 정확히 한 번이 존재
2. 멱등성 프로듀서를 사용하면 프로듀서에서 브로커로 딱 1번 레코드를 전송할 수 있음
3. 트랜잭션 프로듀서, 컨슈머를 사용하면 여러 레코드를 하나의 원자(Atmoic)으로 묶어 보낼 수 있음

-----
### 퀴즈
-----
1. 멱등성 프로듀서는 리더 파티션이 있는 브로커와 여러 번 통신 (X)
2. read_committed로 설정한 컨슈머는 커밋이 완료된 레코드만 읽음 (O)
3. 멱등성 프로듀서는 애플리케이션이 종료될 때 커밋을 수행 (X)
