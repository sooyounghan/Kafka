-----
### 카프카 컨슈머
-----
1. 카프카 컨슈머 : 카프카 클러스터에 저장된 레코드를 받아와서 처리하는 애플리케이션
2. Consumer Group : 동일한 역할을 하는 컨슈머들의 묶음
3. Consumer Lag : 파티션에서 가장 최근의 레코드 오프셋과 컨슈머 오프셋 간의 차이
4. Commit : 컨슈머가 레코드 처리가 완료되었을 경우, 카프카 클러스터에 마지막으로 읽은 레코드 오프셋 번호를 저장하는 작업
5. Rebalancing : 컨슈머 그룹에서 컨슈머 개수의 변화 또는 파티션 개수 변화로 인해 할당이 변경되는 작업
6. auto.offset.rest : 컨슈머 그룹이 없을 경우, 처음 읽을 오프셋의 위치를 지정하는 옵션
7. isolation.level : 트랜잭션이 완료된 레코드를 읽을 것인지 판단하는 옵션
