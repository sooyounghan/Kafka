-----
### 정리
-----
1. 카프카 커넥트는 반복적인 파이프라인 생성 시 유용
   - 커넥트는 커넥터를 실행하기 위해 상용환경에서 분산 운영됨
2. 단일 모드 커넥트는 디버그 또는 에이전트 역할로 수행
3. 커넥트는 커넥트를 실행하기 위한 프로세스
4. 커넥터는 오픈소스 커넥터와 직접 개발하는 커스텀 커넥터로 구분
5. 커스텀 커넥터를 사용하여 싱크 커넥터, 소스 커넥터를 개발할 수 있음
6. 커넥터는 Connector와 Task로 구성
   - Connector는 Task를 운영하는 스레드
   - Task는 실질적으로 동작을 하는 컨슈머 또는 프로듀서 역할을 함

-----
### 퀴즈
-----
1. 카프카 커넥트는 스레드 (X) : 커넥터와 태스크가 스레드로 실행 (커넥트는 프로세스 단위, 실행하는 프로세스 단위는 Worker라고 부름)
2. 모든 오픈 소스 커넥터는 무료로 사용할 수 있음 (X)
3. 싱크 커넥터는 컨슈머 역할을 함 (O)
4. 소스 커넥터는 컨슈머 역할을 함 (X) : 프로듀서 역할
5. 태스크는 커넥터 당 최대 10개까지 띄울 수 있음 (X) : tasks.max에 대해서 태스크 갯수가 정해짐 (일반적으로 싱크 커넥터를 기준으로 파티션 개수와 동일하게 하는 것이 좋음)
