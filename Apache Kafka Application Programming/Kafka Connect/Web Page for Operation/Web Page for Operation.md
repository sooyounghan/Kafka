### 카프카 커넥트를 운영하기 위한 웹 페이지
-----
<div align="center">
<img src="https://github.com/user-attachments/assets/6ebd8023-ee68-4d1e-bdc7-2f49378eeb62" />
</div>

1. 카프카 커넥트는 편리한 REST API 인터페이스를 제공하지만, 지속적으로 파이프라인(싱크 커넥터, 소스 커넥터)를 운영하는데 한계가 있음
2. 따라서, 지속적으로 싱크 커넥터, 소스 커넥터를 조회하고 수정 / 삭제하기 위해서는 웹 페이지가 반드시 필요
3. 커넥트를 운영하기 위한 웹 페이지는 오픈소스를 사용해도 좋고, 직접 만들어서 운영하는 것도 좋음
