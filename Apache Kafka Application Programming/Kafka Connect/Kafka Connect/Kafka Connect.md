### 카프카 커넥트 (Kafka Connect)
-----
<div align="center">
<img src="https://github.com/user-attachments/assets/38467a50-8717-4d98-bb96-f4f231cff9d4" />
</div>

1. 카프카 오픈소스에 포함된 툴 중 하나로, 데이터 파이프라인 생성 시 반복 작업을 줄이고 효율적인 전송을 이루기 위한 애플리케이션
2. 커넥트는 특정한 작업 형태를 템플릿으로 만들어놓은 커넥터(Connector)를 실행함으로써 반복 작업을 줄일 수 있음
   - 커넥트 : 툴의 전체 구조
   - 커넥터 : 실질적으로 내부에서 스레드 형태로 프로듀서나 컨슈머로 실행되는 것 (소스 커넥터 / 싱크 커넥터)

3. 내부 구조
<div align="center">
<img src="https://github.com/user-attachments/assets/0e0ef663-a322-4ba5-ad0d-403f41e1334d" />
</div>

   - 커넥트를 실행하는 것은 REST API로, HTTP 통신으로 커넥터에 있는 파이프라인을 실행 또는 중단, 수정 가능
   - 사용자가 커넥트에 커넥터 생성 명령을 내리면 커넥트는 내부에 커넥터와 태스크를 생성
   - 커넥터(Thread)는 태스크(로직을 실행하는 가장 낮은 단위로 데이터를 처리하는 스레드가 Task Thread)들을 관리
     + 즉, 기본적으로 설정값을 받고, Validation을 주로 실시
     + 태스크는 데이터를 처리하는 스레드
   - 태스크는 커넥터에 종속되는 개념으로 실질적인 데이터 처리를 함
   - 그렇기 때문에, 데이터 처리를 정상적으로 하는지 확인하기 위해서는 각 태스크의 상태를 확인해야 함
