-----
### 오픈소스 커넥터
-----
1. 직접 커넥터를 만들 필요가 없이 커넥터 jar 파일을 다운로드하여 사용할 수 있다는 장점 존재
2. HDFS 커넥터, AWS S3 커넥터, JDBC 커넥터, 엘라스틱서치 커넥터 등 100개가 넘는 커넥터들이 이미 공개되어 있음
3. 필요한 커넥터를 검색하고, 아키텍쳐에 맞는 커넥터를 찾아서 다운받아 사용하면 됨
4. 오픈소스 커넥터의 종류는 컨플루언트 허브(```https://www.confluent.io/hub/```)에서 검색할 수 있음 : 다만, 오픈소스라고해서 모두 무료로 제한없이 사용할 수 있는 것이 아니므로 라이센스를 참고해 사용 범위를 확인한 이후 사용해야 함
