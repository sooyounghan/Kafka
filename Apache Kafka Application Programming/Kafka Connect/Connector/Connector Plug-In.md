### 커넥터 플러그인
-----
<div align="center">
<img src="https://github.com/user-attachments/assets/320fb0ee-12d3-4e77-8666-bcb3a4d56463" />
</div>

1. 카프카 2.6에 포함된 커넥트를 실행할 경우, 클러스터 간 토픽 미러링을 지원하는 미러메이커2 커넥터와 파일 싱크 커넥터, 파일 소스 커넥터를 기본 플러그인으로 제공
2. 이외에 추가적인 커넥터를 사용하고 싶다면, 플러그인 형태로 커넥터 jar 파일을 추가하여 사용할 수 있음
   - 커넥터 jar 파일에는 커넥터를 구현하는 클래스를 빌드한 클래스 파일이 포함되어 있음
3. 커넥터 플러그인을 추가하고 싶다면, 직접 커넥터 플러그인을 만들거나, 이미 인터넷상에 존재하는 커넥터 플러그인을 가져다 쓸 수 있음
