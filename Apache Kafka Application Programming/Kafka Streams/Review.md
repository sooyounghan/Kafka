-----
### 정리
-----
1. 카프카 스트림즈는 자바 라이브러리로 상태 기반, 비상태 기반 데이터 처리에 적합
2. 상태 기반 처리를 위해 RocksDB와 changeLog 토픽을 생성
3. 스트림즈 DSL에는 KStream, KTable, GlobalKTable 개념이 포함되어 있음
4. 프로세서 API는 스트림즈 DSL에 없는 기능을 활용하기 위해 사용

-----
### 퀴즈
-----
1, 카프카 스트림즈는 반드시 자바로 작성해야 함 (X) : 공식적으로 자바 라이브러리만 제공 (JVM으로 제공하는 모든 언어는 호환 가능)
2. 스트림즈 DSL를 사용하면 반드시 KStream을 사용해야 함 (X) : 소스 프로세서는 총 3가지 존재 (KStream, KTable, GlobalKTable)
3. KStream은 토픽을 구체화된 뷰로 활용하는 것 (X) : 구체화 된 뷰를 활용하는 것은 KTable, GlobalKTable
4. GlobalKTable을 사용하면 토픽의 모든 데이터를 한 개 태스크에서 활용할 수 있음 (O) : KTable은 각 태스크마다 1:1 매칭되어 활용되므로 모든 데이터를 활용할 수 없음
5. KTable과 KStream을 Join하기 위해서는 반드시 코파티셔닝이 되어 있어야 함 (O)
6. 코파티셔닝이란 파티션의 개수와 메세지 키에 대한 파티셔닝 전략이 동일한 것을 뜻함 (O)
