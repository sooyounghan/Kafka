### SaaS형 아파치 카프카 소개
-----
1. 클라우드 서비스 - 컨플루언트
   - 컨플루언트는 카프카에 대한 개념을 최초로 생각하고, 아키텍쳐를 제안 및 개발한 인물인 제이 크랩스와 그의 동료들이 설립한 회사
   - 제이 크랩스는 링크드인에서 데이터 인프라를 담당하는 아키텍트 팀장이었는데, 카프카 성장 가능성과 미래를 보고 링크드인을 퇴사하여 추가 기능을 가진 카프카를 제공하는 스타트업 설립
   - 50억 달러 가치를 지녔으며, 한화로 6조 원 가량의 회사로, 아파치 카프카의 생태계를 가꾸고 발전시키는 데 선구적인 역할을 하고 있음
   - 컨플루언트에서 오픈 소스로 공개하고 관리하고 있는 스키마 레지스트리 ksqlDB 등과 같은 소스 코드들은 카프카를 활용하는 생태계 범위를 점차 늘려나가고 있음

3. 클라우드 서비스 - AWS MSK
   - MSK(Managed Streaming for Apache Kafka)는 AWS에서 제공하는 SaaS형 아파치 카프카 서비스
   - AWS MSK는 AWS 인프라에서 카프카 클러스터를 생성, 업데이트, 삭제 등과 같은 운영 요소를 대시 보드를 통해 제공
   - 또한, 안전하게 접속할 수 있도록 클러스터와 연동 시 TLS 인증 보안을 설정할 수 있음
   - MSK로 클러스터를 생성하고자 하는 엔지니어는 아파치 카프카 버전을 직접 선택할 수 있음
   - 그렇기 때문에, 기존에 카프카 클라이언트를 운영하고 있는 기업은 버전 차이에 의한 서비스 연동 이슈를 발생시키지 않고, 안전하게 클러스터를 사용할 수 있다는 장점이 있음
   - MSK로 생성한 클러스터는 AWS에서 제공하는 인프라 영역에 구축됨
   - MSK는 AWS에서 운영하는 애플리케이션과 쉽게 연동할 수 있으므로 AWS를 이미 사용중인 기업에서는 어렵지 않게 아키테쳐 포함 가능
