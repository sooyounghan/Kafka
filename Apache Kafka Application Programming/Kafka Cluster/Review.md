-----
### 정리
-----
1. 아파치 카프카는 직접 설치하거나 SaaS형으로 운영하는 방법이 있음
2. 서비스 운영 형태는 온프레미스, IaaS, PaaS, SaaS가 있음
3. 온프레미스 또는 IaaS에서 오픈소스 카프카를 설치하거나 기업용 설치형 카프카를 사용할 수 있음
4. 대표적인 카프카 클러스터 SaaS 서비스로 AWS MSK와 컨플루언트 클라우드가 있음
5. SaaS로 운영할 경우 인프라 관리 효율화, 모니터링 대시보드 제공, 기본 보안 설정과 같은 장점이 있음
6. SaaS로 운영할 경우 서비스 사용 비용, 커스터마이징 제한, 종속성과 같은 단점이 있음

-----
### 퀴즈
-----
1. 컨플루언트 플랫폼은 클라우드에서 제공하는 SaaS형 카프카이다. (X) 
   - 컨플루언트 플랫폼은 클라우드에서 제공하는 것이 아닌 On-Premise에서 서버를 직접 설치하는 것
   - 클라우드에서 제공하는 SaaS형 카프카는 컨플루언트 클라우드

2. SaaS를 사용하면 비용이 반드시 절감된다. (X)
   - 기본적 인프라 스트럭쳐를 사용하는 데 있어서 비용과 관련된 문제가 높아질 수 있음
   - 일반적으로 절감되지 않음

3. SaaS형 카프카를 사용하더라도 주키퍼는 사용자가 운영해야 한다. (X)
   - 주키퍼도 위임해서 만드므로, 사용자가 운영하지 않는 경우도 많음

4. AWS MSK는 컨플루언트의 대표적인 클라우드 서비스이다. (X)
   - 컨플루언트와 무관하며, AWS 사에서 제공하는 서비스이고, 오픈소스 아파치 카프카를 설치형으로 제공하는 서비스

5. SaaS형 카프카를 사용하면 카프카에 대한 깊은 지식이 없어도 무관하다. (X)
